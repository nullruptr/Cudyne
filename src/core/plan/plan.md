# Plan

いわゆるスケジュール登録票

PK, Goal ID
FK, Category ID
start_time (UTC)
end_time (UTC)
memo

これで完成。

wxGrid で作る。
Excel のような編集を可能にする。

セルは、
id(未定は、"-"), 対象カテゴリID, 左セルを参照してカテゴリパス(編集不可), start_time, end_time, memo

変更をためて、最後に Save でまとめて反映、Discard で破棄

React 版は後で作る。

- 行の削除は、保存するまで取り消せる。保存後も削除可にする。
- 未保存のまま閉じるときは、確認を出す
- 時刻は UTC 保存で、表示と入力はローカル時刻

## 実装(wxGrid 版)

### 表
- 列: ID(編集不可。未保存は "-") / Category ID / Category Path(編集不可) / start_time / end_time / Total(編集不可) / memo。
  `goal_id` は表に出さないが、読み込んだ値を保持し、更新しても変えない。
- 行ラベルに、開始日(ローカル。`YYYY-MM-DD`)を出す。開始時刻を直すと、行ラベルも変わる。
- 時刻は `YYYY-MM-DD HH:MM:SS`(秒なしの `YYYY-MM-DD HH:MM` も可)。入力は確定時にそろえる。
- 上段のいちばん下の行に、選択中の start_time / end_time セルを編集する入力欄がある(Edit ToDo と同じ入力)。
  日付はカレンダーで選び、時刻は `HH:MM`(`1300` のような入力も可)、秒は `SS`。日付を選ぶとすぐ反映し、時刻と秒は Enter かフォーカスが外れたときに反映する。
  「= Now」で現在時刻にできる。対象のセルを選んでいないときは無効。表に直接入力することもできる。
- 行の編集: F2 を押すか、start_time / end_time のセルをダブルクリックすると、Add Rows と同じ画面(`PlanAddDlg`)が**編集モード**で開く。
  - F2 は、セルを編集している最中は効かない(セル内の編集に任せる)。表の既定の「F2 でセル内の編集」は、この画面に置き換わっている。
  - 1 行の編集(カーソルのある行): カテゴリ・日付・時間帯・メモを、まとめて直せる。
    - 日付と時間帯は 1 つずつ(入力方法の wxChoice は出ない)。「Add and continue (F3)」も出ない。カレンダーの「Set date」は、日付を置き換える。
    - 時間帯は、開始と終了の `hhmm` と `ss` に出る。日をまたぐ行は、終了の `hhmm` が 24 時以降になる(開始 2200、終了 2600)。
    - プレビューの重なりは、直す前の自分自身を除いて判定する。
  - **複数行の編集**: 行ラベルで 2 行以上を選んで F2 を押すと、選んだ行をまとめて直す画面になる。
    - 入力欄には、**先頭の行の値**が入る。全行で値が同じ欄は普通の色、行ごとに値が違う欄は**薄い黄色**(マウスを重ねると、先頭の行の値であることをツールチップで示す)。
    - 全行に反映するのは、**自分で触った欄だけ**(打ち込んだ欄、カレンダーで選んだ日付、選び直したカテゴリ)。触らなかった欄は、各行の値のまま。したがって、先頭の行の値をそのまま全行に押し付けることはない。
    - Category: 先頭の行のカテゴリが出る(行ごとに違うときは、その旨を添える)。選び直したときだけ、全行を置き換える。
    - Date: `yyyy` だけ触ると年だけ、`mmdd` だけ触ると月日だけ変わる。両方触る(カレンダーで選ぶのも同じ)と、全行をその日に移す。終了が翌日以降の行は、その差を保つ。存在しない日付になる行(例: 2/29 の年を平年にした)があれば、エラー。
    - Start Time / End Time: `hhmm` と `ss` は、触った欄だけが変わる(`hhmm` だけ触ると、秒は各行のまま。`ss` だけ触ると、時分は各行のまま)。Start Time だけ触ったとき、終了は各行のまま(開始が終了以後になる行があれば、「Row N: End must be after start」のエラー)。
    - Memo: 先頭の行のメモが出る。打ち込んだときだけ、全行のメモを置き換える(空にすることもできる)。
    - プレビューには、選んだ各行の「直したあと」の日時が行番号つきで並び、重なりは赤。直す前の選んだ行どうしは、重なりとして数えない。
    - **1 行だけを直す**: 下のプレビューの行をクリックすると、その行の「いまの結果」の日時が上の入力欄(`yyyy`、`mmdd`、開始と終了の `hhmm` と `ss`)に入り、その行**だけ**を編集できる。上に「Editing: row N only」と出る。
      - その行で触った項目は、その行だけに反映され、**全行向けの修正より優先する**(優先順位: その行だけの修正 > 全行向けの修正 > 元の値)。
      - 「All rows」を押すと、全行の編集に戻る(その行で直した内容は残る)。別の行をクリックして、続けて直すこともできる。
      - 1 行を編集しているときは、入力欄の黄色(行ごとに値が違う印)は付かない。
      - 1 行向けの修正の対象は、日時の項目(`yyyy`、`mmdd`、`hhmm`、`ss`)。Category と Memo は、全行向けだけ。
    - 変更のあった行だけが「変更」(黄)になる。直した行は、開始時刻に合う位置に移り、選択されたままになる。
  - OK (F2) で反映し、Cancel (F12) か Esc で何も変えない。
  - 日時だけを素早く直したいときは、上段の日時入力欄(カーソルのセルを、カレンダー・時刻・秒で直す)か、表への直接入力が使える。
- 行は、開始時刻の順に並ぶ。追加・複製した行は、開始時刻に合う位置(上か下)に入る。
  既存の行の時刻を直しても、その場では並び替えない(Save 後の読み直しで整う)。
- Category ID のセルをダブルクリックすると、カテゴリのツリーから選べる(フォルダは選べない)。
- 色: 新規は薄い緑、変更は薄い黄。上段に未保存の件数(新規 / 変更 / 削除)を出す。

### 絞り込み
- Filter by period(Detail と同じ。From ~ To をカレンダーから選ぶ): ON のとき、期間と重なる予定だけを表示する。OFF はすべて。既定は ON(今月)。
- Category...: カテゴリで絞る。フォルダを選ぶと、配下のタスクの予定がまとまって出る。Clear で解除。
- どちらも変更すると DB から読み直すので、未保存の変更があれば破棄してよいか確認する(取り消すと元の絞り込みに戻る)。

### 空き日の表示(Show empty days)
行ラベルの日付の並びを、次のように切り替える。

| 設定 | 表示 |
|---|---|
| OFF(既定) | 予定のある日だけ。10/01(予定あり)、10/03(予定あり) |
| ON | 予定のない日を、灰色の編集できない行で差し込む。10/01(予定あり)、10/02(灰色)、10/03(予定あり) |

- 空き日の範囲は、期間で絞っているときはその期間、そうでなければ最初〜最後の予定の日。
- 空き日の行は表示だけで、保存・選択・複製・削除の対象にならない。

### 複製
- 行ラベルをクリックして行を選ぶと、キーボードのフォーカスが表に移る(Ctrl+C / Ctrl+V や矢印キーが、直前に触った入力欄に届かないように)。
- Ctrl+C: 選択した行(行ラベルをクリックして選択)の内容をためる。システムのクリップボードにも、タブ区切りの文字列を入れる。
- Ctrl+V: ためた行を、同じ内容で複製する(時刻はそのまま、メモも複製)。セルを編集中のときは、テキストの貼り付けに任せる。
- Duplicate ボタン: 選択した行(なければカーソルの行)を複製する。右側の設定で、元の予定からずらす量を決める。
  - Shift by: 整数(負なら過去)と単位(minutes / hours / days / weeks / months)。開始と終了を同じだけずらす。日・週・月は暦で動かす。
    整数はテキスト欄に入力する(矢印キーやホイールで勝手に値が変わらないように、スピンボタンにはしていない)。整数でない値のときは、複製しない。
  - Copy memo: ON のときだけ、メモも複製する。
- 複製した行は新規扱い(ID は "-")。Goal との紐づけ(`goal_id`)は複製しない。

### 予定の重なり
- 同じカテゴリで、時間が重なる予定は登録できない。同じ時刻(開始も終了も同じ)も重なり。
  一方の終了と他方の開始が同じ(端が接しているだけ)なら、重ならない。
- カテゴリが違えば、同じ時刻でもよい。
- 表では、重なる行を赤で表示し、上段に件数を出す(`[n rows overlap]`)。時刻やカテゴリを直すと、すぐに判定し直す。
- Save は、変更した行が重なっていると、その行に移って中止する。変更していない行どうしの重なり(以前に保存されたもの)は、止めない。
- DB(`Database::ApplyPlanChanges`)でも検査する。反映後の状態で、追加・更新した予定が、同じカテゴリの他の予定(表に出ていないものを含む)と重なれば、すべて巻き戻して失敗する。
- 実装: 重なりの検出は `plan_conflict.hpp`(DB と wx に依存しない)。
- Ctrl+V は時刻をそのまま複製するため、同じカテゴリでは必ず重なる。貼り付けたあとに時刻かカテゴリを直してから Save する(Duplicate の Shift by を使えば、ずらして複製できる)。

### 保存
- Add Row: 日付の組と時間帯の組を掛け合わせて、まとめて予定を作る入力画面(`PlanAddDlg`)が開く。
  入力欄の並びは、日付が「Select Date」+ `yyyy` + `mmdd`、時間が「Start Time」+ `hhmm` + 「:」+ `ss` と「End Time」+ `hhmm` + 「:」+ `ss`。`yyyy`、`mmdd`、`hhmm` の欄にはラベルを付けず、書式はマウスを重ねたときのツールチップに出す。桁がそろうと、次の欄へ進む。`mmdd` はちょうど 4 桁(例: 1021)。`hhmm` は 4 桁(0930)のほか、3 桁(930)や時だけ(9)でもよい。`ss` は、空なら 0。
  - Category: 追加先のカテゴリ(タスク)。初期値は、カーソルのある行のカテゴリ。
  - Dates: 入力方法を wxChoice で選ぶ。選んだ方法に合わせて、入力欄の並びが自動で変わる。
    - One day: `yyyy` と `mmdd` の入力欄が 1 組。
    - Several days: `yyyy` と `mmdd` の入力欄の行を、好きなだけ並べる(「+ Add day」で足す。「x」で消す。足すと、最後の行の翌日が入る)。同じ日は 1 つにまとめる。
    - Repeat: 起点の `yyyy` と `mmdd` + 回数(Times)+ 間隔(Every)+ 単位(days / weeks / months)。
    - カレンダー: 選んだ日付を、入力方法に合わせて反映する(One day = 入力欄を置き換える / Several days = 行を足す / Repeat = 起点にする)。
    - 入力方法を切り替えると、先頭の日付は引き継ぐ。
  - Times: 入力方法を wxChoice で選ぶ。
    - One time range: 開始の `hhmm` と `ss`、終了の `hhmm` と `ss`。
    - Several time ranges: 同じ入力欄の行を、好きなだけ並べる(「+ Add time range」で足す。足すと、最後の行の終了が開始になる)。
    - 終了の時は 71 まで書ける。24 以降は翌日以降(`2600` = 翌日の 2 時)。開始は 0〜23 時。終了は開始より後であること。
  - すべての日付 x すべての時間帯の予定を、一覧(プレビュー)に出す。すでにある予定や、新しく作る予定どうしと重なるものは赤。1 回に作れるのは 500 件まで。「繰り返し」は 366 回まで。
  - Memo: すべての予定に同じメモを入れる。
  - 使い分け: 「毎日同じ時間」= Repeat、または Several days。「決めた日付に、時間だけ同じ」= Several days で日付を並べ、時間帯は 1 つ。「日付は決めて、時間は自由」= One day で、Several time ranges。
  - wxChoice(日付・時間帯の入力方法、Repeat の単位)は、マウスホイールでも切り替えられる(上に回すと前、下に回すと次の項目)。Plan の Duplicate の単位も同じ。
  - キー操作: F2 = 追加して閉じる/ F3 = 追加して開いたまま(続けて入力できる)/ F12 または Esc = 閉じる。Enter では、何も確定しない(押し間違いで追加しないように)。
  - 追加した行は新規(緑)で、開始時刻の順に入る。Save するまで DB には入らない。
- Duplicate(下記)は、すでにある行を、ずらして複製するためのもの。Add Row は、新しい予定を作るためのもの。
- Delete Row: 選択した行(なければカーソルの行)を消す。保存済みの行は、Save するまで DB に残る。
- Save: すべての変更行を検証し、問題があればその行・セルに移って中止する。問題がなければ、追加・更新・削除を 1 つのトランザクションで反映して、読み直す。
- Discard: 確認のうえ、DB から読み直す。
- ウィンドウを閉じるとき、未保存の変更があれば確認する。
- 検証(`Database::ValidatePlanItem`): 時刻が実在する形式であること / 終了 > 開始 / カテゴリが存在し、非表示でなく、フォルダでないこと。
- 上段は、3 つの行に分けている。Filter by period ~ Clear / Show empty days ~ Copy memo / Save 以降(その下に、日時の入力欄)。
- 上下のセパレータ(横線)で、上に表、下に Goal の達成判定を置く。ウィンドウの高さを変えると、上(表)だけが伸縮し、下は固定の高さ。
### Goal の達成判定(下のペイン)

設定した予定で、有効な Goal を達成できるかを、Goal の窓ごとに判定して一覧に出す。
実装: 判定は `plan_check.hpp`(DB と wx に依存しない)、窓への当てはめは `plan_feasibility.hpp`、画面は `PlanCheckPanel`。

- 判定する窓:
  - 期間で絞っているとき(Filter by period が ON)は、その期間と重なる窓のうち、まだ終わっていないもの。
  - 絞っていないときは、今から 30 日先までの窓。
  - 無効な Goal は対象外。ToDo に設定した Goal は、予定が ToDo と結びついていないため「判定できない」と表示する。
- 判定に使う予定: DB に保存済みの予定に、表で編集中(未保存)の変更を重ねたもの。編集すると、少し待ってから自動でやり直す。
  Goal の対象は、その Category 以下の予定(全カテゴリの予定から選ぶ)。
- カテゴリで絞っている(Category...)ときは、そのカテゴリ以下(自分自身と配下のフォルダ・タスク)に設定された Goal だけを表示する。
  判定に使う予定は、絞り込みに関係なく、Goal の対象の全予定。親フォルダの Goal は、絞り込んだカテゴリを含んでいても表示しない。
- 数える予定は、**今以降の分だけ**。すでに過ぎた予定は、実績(record)に現れるので、二重に数えない。進行中の予定は、今から先の分だけ数える。窓の外の分も数えない。
- 残り = 目標 - 実績(例外設定があれば、差し替え後の目標。記録中の分を含む)。

| 判定 | 条件 | 色 |
|---|---|---|
| Achieved | 残り ≤ 0 | 濃い緑 |
| Covered by plans | 窓の中の、今以降の予定の合計 ≥ 残り | 薄い緑 |
| Short by X | 予定の合計 < 残り。ただし、窓の残り時間を休まず使えば間に合う(足りない分 X を表示) | 黄 |
| Impossible (X left) | 残り > 窓の残り時間(休まず使っても間に合わない) | 赤 |
| Overdue | 期限(Rolling のサイクルの n 日)を過ぎている。今以降の予定は参考に数える | 濃い赤 |

- 窓の終点がない Goal(Undefined で End なし)は、期限がないので Impossible にはならない。
- 一覧の列: Goal / Window / Remaining / Planned / Plan - Remaining(予定 - 残り。足りないと負) / Verdict。上に件数の集計を出す。
- 制約: 違うカテゴリの予定が時間的に重なっていても、それぞれの時間を足す(record の集計と同じ考え方。フォルダの Goal では、並行した予定を二重に数える)。
